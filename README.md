# Python Sales Analysis

Executed full-cycle EDA using Pandas and NumPy, performing data cleaning and time-series analysis to identify seasonal sales patterns and market trends. Analyzed supply chain efficiency and profitability across regions, delivering data-driven insights through Matplotlib and Seaborn visualizations.

## Project Structure & Steps
1. **Data Cleaning & Preparation:** Handling missing values, filtering anomalies, and data type formatting via Pandas.
2. **Time-Series Analysis:** Extracting seasonal sales patterns and long-term market trends.
3. **Supply Chain & Profitability:** Regional performance analysis to optimize delivery intervals.
4. **Data Visualization:** Comprehensive insights visualized using Matplotlib and Seaborn.
